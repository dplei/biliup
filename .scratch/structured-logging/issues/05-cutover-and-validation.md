## 范围

- Rust CLI、wheel CLI 和 Python 嵌入式下载/上传入口共用采集策略，避免重复初始化 subscriber。
- 移除应用内 rolling/never 文件 sink 与 WebSocket tail 文件逻辑；保留结构化控制台。
- 非 server 命令默认控制台；若启用数据库持久化，显式配置且生命周期完整，不依赖 Web 服务。
- 旧 WebSocket 参数临时映射为数据库查询别名并标明废弃；兼容入口也必须受认证保护。
- 不自动删除旧日志、不默认导入；写明回退操作和新增库/配置与旧程序的兼容边界。
- 在本地开发环境进行真实录制链路验证，结果脱敏写回本目录；不操作生产或购买云资源。

## 验收

1. 分别运行各支持入口，没有新建或追加 `.log`，控制台和选定持久化模式符合配置。
2. 页面无文件不存在提示，下载走查询导出，旧入口的兼容映射有覆盖测试。
3. 启动失败、日志库失败、正常退出、重启与强杀均验证过，文档如实描述故障损失窗口。
4. 完成并发录制/切片/重连/预处理/上传/投稿的端到端事件链核对，原业务行为不退化。
5. 以证据决定首版保留容量和是否需要云汇总，不以猜测的日志规模购置数据库。
