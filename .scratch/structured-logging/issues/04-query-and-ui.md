# 04 — 历史查询、场次时间线与独立进度视图

Status: needs-triage
Blocked by: 02, 03

来源：[spec](../spec.md)。仅拆分，尚未实现。

## 范围

- 新增带认证的列表、实时流、诊断详情与查询导出接口；保留部署显式关闭认证的现有语义。
- 支持级别/类型/时间/事件名和各类任务关联过滤，限制页长，用游标避免深 OFFSET。
- 使用已提交事件序号接续实时流，处理快照与订阅竞态、重连去重、过期游标与迟到事件。
- 日志页显示中文摘要、级别文字/图标、业务分类和关联入口；详情折叠、缓存有界。
- 复用业务状态展示进度，不把通用日志变成当前任务状态的唯一来源。
- 替换文件式开发者选项和所有日志下载按钮，导出在响应中流式生成。

## 验收

1. 按一场录制可查完整事件链，含后续上传/补传与 skipped 决策。
2. 翻页时持续产生事件仍不重不漏，断线恢复无缺口；过期数据明确提示不可用。
3. 上传进度不会顶掉事件，用户阅读旧记录时滚动位置稳定。
4. 启用认证时未登录无法访问列表、流、附件和导出；导出和错误提示不泄漏凭据。
5. 合成大数据量下检查查询计划、响应时间、前端内存及与录制同时运行时的影响。
