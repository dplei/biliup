# 事件覆盖与迁移清单

Status: needs-triage
来源：[实施计划](rollout-plan.md)、[对比流程](reconciliation.md)。
以下为初始候选，06 负责核对并冻结 v1；所有行目前均为**未接入、未验证**。
事件名是建议契约，不表示源码已存在这些事件；文件/符号仍以实现时的代码索引为准。

对每项补充：适用入口/平台、必填与可空字段、业务关联方式、脱敏规则、旧调用点或明确
没有旧来源、预期一对多/多对一映射、回归场景、证据引用和待关闭差异。
进度快照 C08 与存储健康 C14 可由独立数据源回答，不强求每次更新成为普通事件。

## 支持入口与路径

06 核对实际支持范围，不因「当前只用一种」跳过其他对外入口；未支持范围必须公开注明。

| 入口/路径 | 必查边界 | 当前状态 |
| --- | --- | --- |
| wheel CLI 主循环 | 文件 + 控制台、环境过滤、Web server/非 server 生命周期 | 未验证 |
| Rust CLI | 独立初始化、server/非 server、stdout/stderr | 未验证 |
| Python 下载函数 | 局部 subscriber、宿主已有 subscriber、多次调用、退出 flush | 未验证 |
| Python 上传函数 | 局部 subscriber、宿主已有 subscriber、多次调用、退出 flush | 未验证 |
| HTTP-FLV 与其他受支持下载路径 | callback/Actor/任务传播、稳定分段身份、外部进程 stderr | 待枚举其余路径 |
| 正常上传与重启/补扫/人工补传 | 原分段映射、多个 attempt 不合并、终态与未知态 | 未验证 |
