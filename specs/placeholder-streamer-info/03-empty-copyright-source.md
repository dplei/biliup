# 03 — 转载来源为空时该怎么办

**What to build:** 待定。01 之后，反查不到主播且模板未填转载来源时，投稿提交的是空来源。需要先弄清 B 站对转载稿件的空来源是接受、忽略还是拒收，再决定要不要做，以及做成什么。

**Blocked by:** 01（空来源这个状态是 01 之后才出现的）

**Status:** needs-info

## 需要的信息

真跑一次：用一个 copyright=2（转载）且未填转载来源的上传模板，手动补投一批
反查不到主播的文件，看提交结果。

- 提交成功 → 本票关掉，什么都不用做。
- 被拒收 → 按下面的方向做，AC 届时补齐。
- 提交成功但稿件页显示异常 → 记录实际表现再判断。

## 若确认需要做，方向已定

在提交前校验并给出明确错误，**不由服务端填充默认值**。理由与 01 一致：服务端编造的值会
被原样提交到第三方平台，出了问题无从追溯。正确的落点是让用户在上传模板里显式填写转载来源。

- [ ] 待补：校验发生在哪一层、错误怎么呈现给用户
- [ ] 待补：既有的自动投稿路径（有真实直播间地址）不受影响的验证方式
