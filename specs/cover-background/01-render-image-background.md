# 01 — 背景图渲染与封面预览子命令

**What to build:** 在本地跑一条命令，传入一张图片和一段封面文字，得到一张 JPG——文字压在这张图上，而不是压在纯黑底上。图片不是目标尺寸时自动适配，图片读不出来时安静地退回纯黑而不是让整个渲染失败。命令另外接受两个仅用于本地试效果的参数（压暗、模糊），效果直接烘焙进输出图，不会流向服务端或数据库。

这是整个特性的地基：它让「背景图」这个能力第一次可见、可验证，后续所有票都建立在它之上。

**Blocked by:** 无——可立即开始。

**Status:** ready-for-agent

- [ ] 封面背景枚举新增图片变体，纯黑仍是默认值
- [ ] 背景图按 cover 语义适配画布：等比缩放到刚好覆盖，再居中裁剪掉溢出部分，不拉伸变形、不留边
- [ ] 背景图缺失、无法读取或解码失败时，记录错误并退回纯黑继续渲染，不向上抛错
- [ ] 新增命令行子命令，参数包含文字、背景图、输出路径，以及压暗与模糊
- [ ] 压暗与模糊仅作用于该子命令的输出，不出现在数据库字段中，也不出现在服务端渲染路径上
- [ ] 子命令复用既有的封面渲染函数，不另写一套渲染逻辑
- [ ] 渲染函数的对外签名不变，背景差异全部收敛在选项结构里
- [ ] 既有的十个封面渲染测试全部仍通过（未配置背景时行为不变的回归保证）
- [ ] 新增测试：使用图片背景时输出仍是合法 JPEG，尺寸为 1146×717
- [ ] 新增测试：传入宽高比与画布不同的图，输出尺寸不变，且角落像素取自背景图而非纯黑
- [ ] 新增测试：传入不存在或损坏的图片，不返回错误且退化为纯黑背景
