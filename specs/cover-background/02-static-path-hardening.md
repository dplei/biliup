# 02 — 静态文件接口收口与 HTTP 测试设施

**What to build:** 静态文件接口目前把用户传入的路径直接交给文件服务，等同于任意文件读取——任何人都能顺着它读到服务工作目录之外的文件。本票把它收口到一个统一的路径校验函数上，同时**保证现有功能不受影响**：日志下载和历史记录页的录播视频回放都必须照常工作。

本票另外建立该服务的 HTTP 层集成测试设施，后续的上传接口与预览接口才有地方写集成测试。

**注意**：该接口并非只服务图片，因此**不能**把它收窄到背景图目录——那会直接破坏视频回放与日志下载。只能限定在服务的工作目录内并拒绝穿越。

本票不依赖任何其他票，具备独立的安全价值，可以随时插队优先做。

**Blocked by:** 无——可立即开始。
