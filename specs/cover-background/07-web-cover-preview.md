# 07 — 网页封面预览

**What to build:** 改完封面文字模板后点一下按钮，当场看到成品封面长什么样，不必等到下一次下播走完整条上传流程才发现排版有问题。预览用的是与投稿时完全相同的渲染器，所以预览好看就代表实际产出好看。

预览接口不读数据库、只接收显式参数，因此模板页和主播页可以复用同一个接口，各自传自己那一级的值。

背景文件名可以手工填写（例如已用 scp 放好图），因此本票不依赖上传功能，可与 06 并行。

**Blocked by:** 01（需要图片背景渲染能力）、02（需要其建立的集成测试设施）

**Status:** ready-for-agent

- [ ] 新增预览接口，接收「文字模板字符串」与「背景文件名」两个显式参数
- [ ] 接口不读取数据库，因此可被多个页面复用
- [ ] 接口内部展开占位符、按换行标记切行，复用与投稿时相同的渲染函数，直接返回 JPG 字节
- [ ] 模板编辑表单新增预览按钮，点击触发
- [ ] 不做输入防抖式的自动重渲，避免每次敲键盘都在服务端编码一张 JPG
- [ ] 背景参数缺省时返回纯黑底封面
- [ ] 参数非法时返回错误状态码
- [ ] 集成测试：给定文字与背景返回合法 JPEG
- [ ] 集成测试：背景参数缺省时返回纯黑底封面
- [ ] 集成测试：参数非法时返回错误状态码
