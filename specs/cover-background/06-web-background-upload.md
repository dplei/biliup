# 06 — 网页上传背景图

**What to build:** 在上传模板的编辑页面选一张图直接上传，不需要登录服务器、不需要 scp。上传后表单里就保存了这张图的文件名，投稿时的封面便以它为背景。

这一票是「摆脱终端」的核心价值所在，也是本特性里工作量最大的部分之一。

**Blocked by:** 03（需要背景字段存在才有地方保存文件名）、02（复用其路径校验函数，并需要其建立的集成测试设施）

**Status:** ready-for-agent

- [ ] 新增 multipart 上传接口，接收单个图片文件
- [ ] 校验扩展名与实际的图片文件头，非图片内容被拒绝
- [ ] 复用 02 的路径校验函数，根目录取背景图目录——不另写一套校验规则
- [ ] 文件落盘到已挂载的数据卷内，随现有备份一起被覆盖
- [ ] 恶意文件名不会在目录之外产生文件
- [ ] 接口返回文件名，供表单保存进背景字段
- [ ] 模板编辑表单在既有的封面相关字段旁新增背景图字段与上传控件
- [ ] 沿用现有表单组件库，不引入新的 UI 依赖
- [ ] 集成测试：合法图片上传成功且文件确实落盘
- [ ] 集成测试：非图片内容被拒绝
- [ ] 集成测试：恶意文件名不产生目录外的文件
