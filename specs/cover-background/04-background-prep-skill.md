# 04 — 背景图处理 skill

**What to build:** 用户把一张原图交给 Claude，Claude 负责把它变成一张适合压文字的背景图：裁切到目标尺寸、试出合适的压暗与模糊参数、渲染样图并**自己查看效果**、迭代到文字清晰为止，最后输出一张可直接使用的成品图。

这解决的是「我不是做设计的，不知道该压暗多少、模糊多少」——调参的人从用户变成 Claude，而 Claude 能真的看到渲染结果，不是凭空猜。

职责边界要写死在 skill 里，避免它越界。

**Blocked by:** 01（需要能渲染样图的命令行子命令）

**Status:** ready-for-agent

- [ ] 仓库内新增 skill，与根目录既有的那个「操作 CLI 工具」的 skill 相互独立、互不干扰
- [ ] skill 通过 01 提供的命令行子命令渲染样图，并在迭代过程中实际查看渲染出的图片
- [ ] 输出的成品图尺寸为 1146×717，可直接作为背景使用
- [ ] skill 明确不从零生成背景图（只处理用户给的图）
- [ ] skill 明确不调整字号、行距、边距、文字颜色等排版参数
- [ ] skill 明确不上传到服务器、不持有任何生产环境凭据
- [ ] 整个流程不依赖本机安装 ImageMagick、ffmpeg 或 Python 图像库
- [ ] 用一张实际的图走通一遍完整流程，确认迭代能收敛到文字清晰
